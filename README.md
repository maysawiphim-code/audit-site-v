# ตัวตรวจรายงานจับตัวเลข (สำหรับ Google AI Studio)

ตรวจไฟล์รายงานจับตัวเลขทำเล (.xls / .xlsx) และชีตผลต่างวันที่ 1 กับวันที่ 2 แล้วให้ Gemini อธิบายผลเป็นภาษาไทย

## หลักการ
- **ตัวเลขทุกตัวคำนวณด้วยโค้ด** (`src/engine/core.ts`) ไม่ได้ให้ AI คำนวณ
- **ไฟล์ Excel ถูกอ่านในเบราว์เซอร์** ไม่ได้ส่งขึ้นเซิร์ฟเวอร์
- **กดปุ่ม "อธิบายผลตรวจ"** แอพจะส่ง "ผลตรวจที่สรุปแล้ว" ไปให้ Gemini ผ่าน `/api/explain` ข้อมูลที่ส่งคือชื่อทำเล รหัส รายการจุดผิด และตัวเลขดิฟรายชั่วโมงที่เกินเกณฑ์ ไม่ได้ส่งไฟล์ Excel
- **คีย์ Gemini** อยู่ฝั่งเซิร์ฟเวอร์ (`GEMINI_API_KEY`) ไม่อยู่ในหน้าเว็บ

## นำเข้า Google AI Studio (โหมด Build)
1. สร้าง repository ใหม่บน GitHub (ตั้งเป็น Private)
2. กด **Add file → Upload files** แล้วลากไฟล์และโฟลเดอร์ทั้งหมดในโปรเจกต์นี้ขึ้นไป แล้วกด Commit
3. เปิด https://aistudio.google.com → **Build**
4. ในกล่องพิมพ์ กดปุ่ม **+** แล้วเลือก **Import from GitHub** จากนั้นเลือก repository ที่สร้างไว้
5. AI Studio จะตั้ง `GEMINI_API_KEY` เป็น secret ให้อัตโนมัติ ดูได้ที่แผง Secrets
6. ทดสอบ: วางไฟล์รายงาน (และไฟล์ผลต่างถ้ามี) แล้วกด **อธิบายผลตรวจ**

> ฟีเจอร์ Import from GitHub ยังค่อยๆ เปิดให้ผู้ใช้ ถ้ายังไม่เห็นเมนูนี้ ให้รันในเครื่องตามหัวข้อถัดไปไปก่อน

## รันในเครื่อง
```
npm install
cp .env.example .env     # ใส่ GEMINI_API_KEY
npm run dev              # เปิด http://localhost:3000
```
สำหรับใช้งานจริง: `npm run build` แล้ว `npm start`

## ตั้งค่า
- `GEMINI_MODEL`: รุ่นโมเดล ค่าเริ่มต้นคือ `gemini-flash-latest`
- เกณฑ์ดิฟรายชั่วโมงปรับได้ในหน้าแอพ ค่าเริ่มต้น 20%
- ชั่วโมงที่ต่างกันน้อยกว่า 10 คน หรือ 100 คัน จะไม่ถูกแจ้ง

## สิ่งที่แอพสมมติไว้
- ชีตผลต่างเป็นเลขสะสมของแต่ละเครื่องนับ ผลต่างรายชั่วโมงคือเลขที่เพิ่มขึ้นจากชั่วโมงก่อน
- ชั่วโมงที่ 1 ของผลัดเช้า บ่าย และดึก เริ่ม 06:30, 14:30 และ 22:30 ตามลำดับ
- ยอดรถในชีตผลต่าง เทียบกับแถว "รถผ่านหน้าฝั่งเป้าหมาย" ในชีต data

## โครงสร้าง
- `src/engine/core.ts`: กฎตรวจทั้งหมด
- `src/engine/readBook.ts`: อ่านเซลล์ กล่องข้อความ และแหล่งข้อมูลกราฟจากไฟล์
- `src/App.tsx`: หน้าแอพ
- `server.ts`: เซิร์ฟเวอร์และ `/api/explain` ที่เรียก Gemini

## การใช้ข้อมูลและค่าใช้จ่าย
- ถ้าแชร์แอพ การเรียก Gemini ของทุกคนจะนับรวมกับโควตาและค่าใช้จ่ายของเจ้าของคีย์
- ถ้าใช้คีย์แบบฟรี ควรตรวจเงื่อนไขการใช้ข้อมูลของ Google และถามฝ่าย IT ก่อนใช้กับข้อมูลทำเลจริง
